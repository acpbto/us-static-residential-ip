## 三种“美国 IP”的区别：双 ISP、原生、真实民房各是什么

市面上标着“美国住宅 IP”的产品分三类，价格能差一倍以上，风控表现也不一样。

| 类型 | IP 从哪来 | 风控表现 | 适合什么 |
| --- | --- | --- | --- |
| 普通机房 IP | IP 归属数据中心 | 容易被识别为 Hosting/Datacenter，平台降权、限流 | 对 IP 类型不敏感的挂机、测速 |
| 双 ISP 家宽住宅 IP | IP 段注册在两个 ISP 名下，机器仍在 IDC 机房，走 9929、4837、NTT 等线路 | IP 数据库识别为家宽属性 | TikTok 矩阵、跨境电商注册、社媒养号、ChatGPT 固定出口 |
| 真实民房家宽 VDS | 硬件托管在美国真实民房，IP 由 Atlas Networks、Astound Broadband、T-Mobile/Frontier 等家庭宽带运营商分配 | 最接近真人宽带 | 亚马逊店铺、Stripe/PayPal、美国银行账号、TikTok 主号长期养号 |

原生 IP 说的是 IP 注册地和服务器实际所在地一致，原生 IP 不等于住宅 IP；双 ISP 也不等于真实民房。静态的意思是 IP 开通后固定给同一个用户，不像动态住宅代理频繁轮换，账号身份才能延续。

**9929 和 4837 怎么选？** 9929 延迟低，适合电信、联通访问和延迟敏感业务，带宽小、价格高；4837 带宽大、便宜，适合大流量和对延迟不敏感的业务。

**双 ISP 和真实民房 VDS 差在哪？** 双 ISP 的 IP 段注册在 ISP 名下，机器还在机房；真实民房 VDS 的机器在民房，IP 由当地宽带运营商分配。后者更接近真人宽带，价格也更高。

**IP 会变吗？** 静态产品开通后 IP 固定。纽约 CN2 NAT 共享是共享 IP，不是独享。

**能装 Windows 吗？** 可以，提交工单，建议至少 2GB 内存。

**国内访问快吗？** 9929 和 4837 是大陆优化线路；家宽 VDS 不是，官方建议中转加 BBR。

**能退款吗？** 开通 48 小时内符合条件可全额退款；家宽 VDS 只退网站余额；纽约 CN2 NAT 共享无退款。
